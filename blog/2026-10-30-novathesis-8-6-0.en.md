The codename is a small joke: an albatross crossing the Atlantic, for a school
called **Atlântica** whose first supported degree is in aeronautics.

## Atlântica — Instituto Universitário

`school=atlantica/cea` covers the BSc in Ciências da Engenharia Aeronáutica:

```latex
\ntsetup{school=atlantica/cea}
```

It follows the school's *Normas para Apresentação e Discussão do Projecto Final
de Licenciatura* (February 2019), and, where the regulation says nothing, the
layout of a dozen real Atlântica theses. A4, two-sided, Times New Roman 12pt at
1.5 line spacing with 12pt after each paragraph, footnotes at 8pt, margins of
3 / 3.5 / 3.5 (inner) / 2.5 (outer) cm, the header 1.8cm and the footer 1.5cm
from the edge of the paper, and chapters opening on right-hand pages. Every
page carries the title and the degree name in the header, and the author, the
date and the page number in the footer.

You get the cover and the title page (without figures), the *sole
responsibility* statement on a right-hand page of its own, an optional
dedication, and an optional reproduction declaration on the back of the title
page.

One caveat about that last one: it is **off** by default, and its text is a
generic placeholder — the official wording is on Atlântica's intranet. Turn it
on with `\ntsetup{print/copyright=true}` in `0-Config/1_novathesis.tex`, and
replace the text with the official one before you submit.

## The student number on the cover

A new command for `0-Config/3_cover.tex`:

```latex
\SetAuthorStudentNumber*()={12345}
```

Only the Atlântica covers print it. Everywhere else it is accepted and ignored,
so there is nothing to undo if you change school, and the line is simply left
out when no number is set.

## And a fix that travels much further than Atlântica

Atlântica's rules ask for Times New Roman. The template has had a `times` font
style for years — and under LuaLaTeX or XeLaTeX it needed Times New Roman,
Helvetica and Courier New to be installed on the machine. On Overleaf and on
most Linux systems they are not, so `style/font=times` failed outright.

Each missing font is now replaced by its metric-compatible TeX Gyre clone,
which ships with TeX Live: Termes for Times New Roman, Heros for Helvetica,
Cursor for Courier New. Metric-compatible is the part that matters — the
substitute takes up exactly the space the original would, so line and page
breaks do not move.

The three are checked separately, so a machine that has Times New Roman but not
Courier New uses the real Times and the clone for monospace. The colophon names
the fonts the build actually used, so the PDF reports what it was set in rather
than what it asked for.

If you had given up on `style/font=times` because it would not compile on
Overleaf, it compiles now.

## Since the last post here

Two releases went by without an announcement on this blog.
**8.4.0 — Crane: Same Flight, New Name** renamed Instituto Politécnico de
Lisboa and de Setúbal to Universidade Politécnica, and with them the school
ids: `ipl/isel` is now `upl/isel`, and `ips/ests` is now `ups/ests`. There is no
backward-compatible alias, so a document still using the old id stops with a
clear error. **8.5.0 — Kingfisher: Landing Where There Is No Water** made the
template record which commit it was built from, added `make info` for bug
reports, gave downloaded fonts and the SDG icons a fallback when shell escape
is off, and — this one is breaking — made the glossary and symbols lists show
only the entries actually cited, as the acronyms list always did. Bring the old
behaviour back with `\ntsetup{glossaries/addall=true}`.

The full list is in the
[changelog](https://github.com/joaomlourenco/novathesis/blob/main/CHANGELOG.md).
