Contributing

New schools, corrections to formatting rules and documentation fixes are all welcome. The template is only compliant because people report where it is not.

Add a school

Open a New school issue with a link to your school's media kit (logos and other image material) and to the official thesis formatting guidelines. School definitions live in novathesisFiles and are self-contained.

Fix a rule

If your institution changed its requirements, open an issue with the document that states the change.

Improve the docs

The wiki is editable and the README is in the main repository. Corrections are as valuable as code.

Translate

Language files cover cover pages and fixed strings. New languages are welcome — and so are corrections to the existing ones, some of which were translated automatically.

novathesis

novathesis is not an official template issued by any of the institutions listed. Compliance is pursued from public documentation — always check your institution's current regulations before submission.
