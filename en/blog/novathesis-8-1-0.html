novathesis 8.1.0 — Peacock: New Plumage

The template is renamed to novathesis, gains a proper colophon page, and drops its last external dependency.

This is the release where the template got its new name and lost its last external dependency.

The name is now novathesis

Written with nova in semibold and thesis in light, and shipped as insignia and wordmark SVGs that need no font installed. In a document, \novathesis renders the logo under LuaLaTeX and XeLaTeX, and the wordmark otherwise.

Breaking: NOVAthesisFiles is now novathesisFiles

The support directory was renamed to lower case. macOS and Windows will not notice — Linux, Overleaf and CI are case-sensitive, and there any local customization, script or .gitignore rule that still spells the old name will stop resolving. Search your project for NOVAthesisFiles and lower-case the NOVA.

A real Colophon page

Replacing the old mini-colophon: multilingual, with the template logo, the full citation, the font in use, the PDF/A status and a build id, shown according to your docstatus.

Citing the template

The reference now goes into your document's own bibliography, CITATION.cff makes GitHub show a Cite this repository button, the entry has a DOI, and the build tells you at the end that the reference was added. The old hidden white 0.01pt citation is gone, and so is the opt-out.

One fewer dependency

The external options package has been replaced by an internal l3keys engine. Every registry — persons, files, lists, print order, languages — moved across, and the old code was deleted. \ntsetup is unchanged: this is one fewer thing to install and one fewer source of surprises.

Also new: SDG icons download on demand, the Jost font style, optional per-type glossary group headings, and a declaration of AI usage for UMinho. The full list is in the changelog.
