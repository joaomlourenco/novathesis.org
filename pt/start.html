Começar

Quatro passos de uma máquina limpa até uma tese compilada. Se preferes não instalar nada, tens editores no browser mais abaixo.

01

Instalar LaTeX

TeX Live em Linux e Windows, MacTeX em macOS. O MikTeX também funciona.

02

Descarregar o repositório

Usa o ZIP da tua escola, ou clona-o se quiseres receber actualizações.

03

Preencher os teus dados

Título, autor, orientadores, grau e língua, tudo em 0-Config.

04

Compilar

Corre make, ou latexmk. Bibliografia e glossários são tratados automaticamente.

Compilação local

Com o latexmk, o biber e o bib2gls instalados, um comando compila o documento, a bibliografia e os glossários. O bib2gls vem com o TeX Live, mas precisa de um ambiente de execução Java (JRE) na tua máquina — confirma com bib2gls --version.

ScienHub

Gratuito

Um editor LaTeX gratuito no browser, com edição colaborativa em tempo real e controlo de versões Git. O limite de compilação é suficiente para compilar o template actual, o que o torna uma alternativa viável a um plano pago do Overleaf.

Não há importação direta: descarrega o ZIP da tua escola, carrega-o num novo projeto no ScienHub e define o template.tex como documento principal.

Abrir o ScienHub

Prism

Gratuito

Um editor de LaTeX assistido por IA, da OpenAI, de utilização gratuita.

Não há importação num clique: entra na conta e carrega o ZIP da tua escola, definindo template.tex como documento principal.

Abrir o Prism

Overleaf

Requer plano pago

Abre o template no browser, sem instalação. Recomendado para documentos curtos e orientação partilhada.

O template não compila no plano gratuito do Overleaf: o limite de 20 segundos de compilação é curto para o novathesis — é necessária uma subscrição paga.

O botão abaixo abre a versão actual diretamente do repositório principal, e não o template oficial desactualizado do Overleaf.

Abrir no Overleaf

O Overleaf ofereceu ao projeto uma conta paga temporária para o template poder ser testado na sua plataforma.

Inscrive

Requer plano PRO

Um editor no browser mais recente, que aceita a mesma importação num clique do Overleaf, directamente do repositório da tua escola.

O template precisa de uma conta PRO para compilar, tal como no Overleaf.

Abrir no Inscrive

O Inscrive ofereceu ao projeto uma conta PRO de longa duração para o template poder ser testado na sua plataforma.

novathesis

O novathesis não é um template oficial de nenhuma das instituições listadas. A conformidade é procurada a partir de documentação pública — confirma sempre os regulamentos actuais da tua instituição antes da entrega.
