Começar

Quatro passos de uma máquina limpa até uma tese compilada. Se preferes não instalar nada, usa o Overleaf ou o ScienHub.

01

Instalar LaTeX

TeX Live em Linux e Windows, MacTeX em macOS. O MikTeX também funciona.

02

Descarregar o repositório

Usa o ZIP da tua escola, ou clona-o se quiseres receber actualizações.

03

Preencher os teus dados

Título, autor, orientadores, grau e língua, tudo em 0-Config.

04

Compilar

Corre make, ou latexmk. Bibliografia e glossários são tratados automaticamente.

Compilação local

Com o latexmk, o biber e o bib2gls instalados, um comando compila o documento, a bibliografia e os glossários. O bib2gls vem com o TeX Live, mas precisa de um ambiente de execução Java (JRE) na tua máquina — confirma com bib2gls --version.

make

Overleaf

Requer plano pago

Abre o template no browser, sem instalação. Recomendado para documentos curtos e orientação partilhada.

O template não compila no plano gratuito do Overleaf: o limite de 20 segundos de compilação é curto para o novathesis — é necessária uma subscrição paga.

O botão abaixo abre a versão actual directamente do repositório principal, e não o template oficial desactualizado do Overleaf.

Abrir no Overleaf

ScienHub

Gratuito

Um editor LaTeX gratuito no browser, com edição colaborativa em tempo real e controlo de versões Git. O limite de compilação é suficiente para compilar o template actual, o que o torna uma alternativa viável a um plano pago do Overleaf.

Não há importação directa: descarrega o ZIP da tua escola, carrega-o num novo projecto no ScienHub e define o template.tex como documento principal.
