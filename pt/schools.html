Cada repositório é uma cópia pronta a usar do template principal, pré-configurada para uma instituição e sincronizada automaticamente. Reconhece a tua capa e usa esse repositório.

Overleaf importa o repositório para um novo projeto no Overleaf — requer um plano pago, porque o template não compila dentro do limite de 20 segundos do plano gratuito. O Inscrive importa o mesmo repositório da mesma maneira, para um projeto próprio, e também precisa de uma conta PRO para compilar. Alternativas gratuitas incluem o ScienHub e o Prism, onde carregas o ZIP manualmente.
