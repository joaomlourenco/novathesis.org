Cada repositório é uma cópia pronta a usar do template principal, pré-configurada para uma instituição e sincronizada automaticamente. Reconhece a tua capa e usa esse repositório.

Overleaf importa o repositório para um novo projecto no Overleaf — requer um plano pago, porque o template não compila dentro do limite de 20 segundos do plano gratuito. Uma alternativa gratuita é o ScienHub, onde carregas o ZIP manualmente.
